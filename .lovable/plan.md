# แก้ไขแท็บ "สรุปผู้บริหาร" ในหน้ารายงาน

## ปัญหาที่ตรวจพบ (ยืนยันแล้ว)

แท็บสรุปผู้บริหารแสดงค่าว่างทั้งหมด: ผ่านเป้าหมาย 0/0, เฝ้าระวัง 0, ต่ำกว่าเป้าหมาย 0, การ์ดวัตถุประสงค์ทั้ง 4 ด้านเป็นขีด "—" และรายการ 5 อันดับขึ้นว่า "ทุกตัวชี้วัดผ่านเป้าหมาย" ทั้งที่ในฐานข้อมูลมีข้อมูลปี 2569 อยู่จริง

สาเหตุ: ตอนดึงรายการตัวชี้วัดของแท็บนี้ ไม่ได้ดึงข้อมูลช่อง "สถานะใช้งาน" มาด้วย ตัวคำนวณจึงมองว่าไม่มีตัวชี้วัดลูกที่ใช้งานอยู่เลย ค่าของ KPI/วัตถุประสงค์ทุกตัวจึงกลายเป็นว่าง (หน้า Dashboard และแท็บอื่นดึงช่องนี้มาครบ จึงแสดงค่าได้ปกติ)

## สิ่งที่จะแก้

- ดึงช่องที่ตัวคำนวณต้องใช้ให้ครบในแท็บสรุปผู้บริหาร (สถานะใช้งาน และความถี่การเก็บข้อมูล) เพื่อให้ค่าเฉลี่ยคำนวณออกมาเหมือนหน้า Dashboard และแท็บสรุปรายเดือน
- ตรวจว่าตัวเลขสถิติ (ผ่านเป้า / เฝ้าระวัง / ต่ำกว่าเป้า) นับเฉพาะ KPI ที่มีข้อมูลจริง และเปอร์เซ็นต์คิดจากจำนวนที่มีข้อมูล
- ตรวจว่าค่าเฉลี่ยของวัตถุประสงค์ทั้ง 4 ด้าน และ KPI4 (สูตร 100 ลบค่าเฉลี่ยลูก) ตรงกับที่แสดงบนหน้า Dashboard และรายงานประจำปี

- เปรียบเทียบค่าเฉลี่ยแต่ละ Objective/KPI ในแท็บสรุปผู้บริหาร กับหน้า Dashboard (ตัวกรอง "ทุกไตรมาส") ให้ตรงกัน
- รัน typecheck และชุดทดสอบเดิมให้ผ่าน
